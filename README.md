# In The Hole Brat — Dive Shop (Website Starter)

A minimal, responsive static website for the dive shop "In The Hole Brat". This is a starter you can customize and deploy quickly.

Files included:
- index.html — main site
- styles.css — styles and responsive layout
- script.js — small client-side interactions (nav, booking form)
- favicon.ico — optional placeholder (not included)

Run locally:
1. Place files in a folder.
2. Open `index.html` in your browser, or run a local static server:
   - Python 3: `python -m http.server 8000`
   - Node (serve): `npx serve .`

Deploy:
- GitHub Pages: push to `gh-pages` (or `main`) and enable Pages in repository settings.
- Netlify / Vercel: connect the repo and deploy — these hosts auto-detect static sites.

Customizing:
- Replace placeholder text, contact details, and trip info in `index.html`.
- Swap the decorative `.wave` block with an image (replace .hero-visual content).
- Hook the booking form to an email provider / server endpoint or use a form provider (Formspree, Netlify Forms, etc.).
